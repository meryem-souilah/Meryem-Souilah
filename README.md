Citizen platform for reporting urban incidents, with automatic classification of reports by an LLM microservice deployed with Docker and CI/CD.
`Jakarta EE` `React` `FastAPI` `Llama 3.3` `Docker`

**RailGIS Maroc**

`Python` `PostGIS` `FastAPI` `Leaflet.js`
